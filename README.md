Аддон улучшает стандартную карту мира, делая её удобнее и информативнее. 

- Изменение размера, положения и прозрачности карты. 
- Отображение координат игрока и курсора. 
- Скрытие тумана войны. 
- Улучшенные значки игроков из пати и рейда на карте. 
- Настройка отображения целей квестов. 
- Убирает лишние рамки и элементы стандартной карты. 

/mapster - открывает окно настроек, либо по кнопке в углу карты.
